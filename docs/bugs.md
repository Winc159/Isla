# Isla Bug 记录

当前尚未进入实现阶段，没有已知运行时 Bug。

记录 Bug 时使用以下格式：

```md
## BUG-YYYYMMDD-序号：简短标题

- 状态：待确认 / 已复现 / 修复中 / 已修复 / 不处理
- 发现版本：
- 环境：Windows / macOS / Linux，Node 版本
- Provider：OpenAI / DeepSeek / Local / Core / CLI
- 现象：
- 最小复现步骤：
- 期望行为：
- 实际行为：
- 原因：
- 修复与验证：
- 关联测试：
```

禁止在 Bug 文档中粘贴 API Key、Authorization Header、完整环境变量或私人会话内容。
